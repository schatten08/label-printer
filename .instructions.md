# Инструкции для GitHub Copilot (Agent Instructions)

Ты — экспертный ИИ-ассистент, помогающий в разработке проекта **Brother Label Printer**. Этот проект является кроссплатформенным инструментом для печати этикеток на принтерах Brother (Windows/macOS).

## Основные принципы разработки

1.  **Соблюдение кроссплатформенности**: 
    - Любое изменение в GUI должно быть синхронизировано между `src/windows_version/print_gui.py` и `src/mac_version/print_gui_mac.py`.
    - Используй стандартную библиотеку `urllib.request` вместо `requests`, чтобы минимизировать внешние зависимости для конечного пользователя.

2.  **Локализация (i18n)**:
    - Все новые тексты интерфейса ОБЯЗАТЕЛЬНО добавлять в словарь `LANGS` для обоих языков (`ru` и `en`).
    - После добавления ключей в `LANGS`, не забывай обновлять функцию `update_texts()`.

3.  **Документирование (КРИТИЧЕСКИ ВАЖНО)**:
    - После каждого масштабного или функционального изменения (добавление фичи, рефакторинг, исправление критического бага) ты ОБЯЗАН:
        1. Обновить `CHANGELOG.md`: добавить новую версию или дополнить текущую в секции `## [Unreleased]` или под актуальной датой.
        2. Обновить `README.md`: если изменился способ установки, требования или логика работы вкладок.

4.  **Работа с принтерами**:
    - **Windows**: Используется bPAC SDK через `pywin32`. Шаблоны — `.lbx`.
    - **macOS**: Используется `brother_ql` (RAW печать) и генерация изображений через `Pillow`.

5.  **Система обновлений**:
    - Поддерживай двойную логику: `git pull` для тех, у кого есть Git, и GitHub API Fallback для тех, кто скачал ZIP-архив.
    - При изменении логики обновления всегда тестируй путь к `project_root` (на 2 уровня выше файла скрипта).

## Правила внесения правок
- Всегда читай `README.md` перед внесением изменений, чтобы понимать текущую архитектуру.
- Сохраняй стиль именования переменных и функций (snake_case).
- При редактировании файлов используй инструмент `replace_string_in_file` с достаточным контекстом (3-5 строк), чтобы избежать ошибок в похожих блоках кода.
