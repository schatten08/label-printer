# Changelog

Все изменения в проекте будут документироваться в этом файле.

## [2.0.0] - 2026-05-25
### Рефакторинг (Windows)
- **Полный отказ от PowerShell**: Windows-версия переписана на чистый Python с использованием библиотеки `pywin32`. Теперь программа напрямую управляет COM-объектами (`bpac.Document`), что устраняет задержку запуска PowerShell, решает проблемы с корпоративными политиками исполнения скриптов (ExecutionPolicy) и делает проект чище.
- **Потокобезопасность COM**: Установлен вызов `pythoncom.CoInitialize()`, чтобы печать работала в асинхронном неблокирующем потоке GUI.
- Обновлено безопасное закрытие процесса печати через проверку атрибутов `callable` для `EndPrint` и `Close` во избежание бага типов boolean.

## [1.6.0] - 2026-05-22
### Улучшено (macOS)
- **Прямая печать через `brother_ql` (RAW)**: Полностью обошли штатную систему масштабирования macOS CUPS, которая ломала размеры этикеток для непрерывной ленты. Теперь для Mac генерируются сырые бинарные инструкции, которые отправляются через `lp -o raw`.
- **Оптимизация под ленту 62мм (DK-22212)**: Полностью переписаны параметры виртуального холста, чтобы максимально компактно разместить штрихкод на широкой 62-мм ленте (штрихкод теперь печатается поперек ленты, имитируя оригинальный узкий размер).
- **Нулевые отступы**: В библиотеке `python-barcode` принудительно отключены тихие зоны (quiet-zones), а также обрезаны все поля в Pillow. Печать идет от края до края с максимальным КПД 62-миллиметрового рулона.
- **Совместимость графики (Pillow)**: Добавлен monkey_patch для `PIL.Image.Resampling.LANCZOS`, который заменяет устаревший атрибут `ANTIALIAS`. Это гарантирует, что программа не упадет на свежих версиях Python.

## [1.5.0] - 2026-05-22
### Улучшено
- **Интеллектуальный поиск серийников**: Программа теперь умеет находить нужный штрихкод, даже если отсканированный с железа номер содержит лишние суффиксы или префиксы от завода-изготовителя (алгоритм ищет совпадение по подстроке от 5 символов).
- **Мгновенный автофокус**: При вставке таблицы из Excel (Ctrl+V или ПКМ) курсор автоматически перепрыгивает в строку сканера, избавляя инженера от лишних кликов мышкой.
- Обновлены тексты и описания элементов интерфейса во вкладке сканера для большего понимания возможностей работы напрямую с оборудованием.

## [1.4.0] - 2026-05-13
### Добавлено
- **Пользовательский выбор принтера (Dropdown)**: В графический интерфейс (как для Windows, так и для macOS) добавлен выпадающий список. Программа сканирует все принтеры в системе, пытается угадать нужный (Brother/QL), но при этом позволяет пользователю вручную выбрать любой вариант из выпадающего меню, если автоопределение ошиблось (например, если принтер называется крайне нестандартно).

## [1.3.0] - 2026-05-13
### Улучшено
- **Автоопределение принтеров (Самоконфигурация)**: Программа теперь сама находит подключенные принтеры Brother. На Windows `print.ps1` сканирует COM-устройства и выбирает нужный принтер, игнорируя копии (например, "QL-810W (Копия 1)"). На macOS скрипт автоматически парсит вывод `CUPS` (`lpstat -p`), освобождая пользователя от необходимости менять код.
- **Улучшенный UX ошибок**: Если принтер выключен или не установлен, программа покажет понятное диалоговое окно (MessageBox) с описанием ошибки, вместо тихого краша PowerShell / CUPS.

## [1.2.0] - 2026-05-13
### Добавлено
- **Вкладочный интерфейс**: Программа разделена на два режима работы ("Массовая печать" и "Сканер коробок").
- **Режим сканера (Dictionary Scanner Mode)**: Новая вкладка для связывания Серийных номеров (SN) и Инвентарных номеров (Label). Позволяет сканировать SN с коробки автоматическим сканером и мгновенно печатать соответствующую этикетку.
- **Аудио-отклик**: Добавлены звуковые уведомления об успешном сканировании (высокий писк) и ошибках (низкий гудок) через `winsound` на Windows и `afplay` на macOS.
- **Умный парсинг таблиц**: Поддержка вертикальной и горизонтальной вставки данных словаря напрямую из Excel/ServiceNow.
- **Очистка префиксов сканера**: Автоматическое игнорирование префикса `S` при аппаратном сканировании штрих-кодов серийных номеров.
- **Контекстное меню**: Добавлена поддержка правой кнопки мыши (Копировать/Вставить/Вырезать) и починен шорткат `Ctrl+V` (с помощью проверки `keycode`) для русской раскладки клавиатуры.
- Версия для **macOS** полностью синхронизирована с новым функционалом Windows-версии.

## [1.1.0] - 2026-05-13
### Добавлено
- **Поддержка macOS**: Добавлена альтернативная версия скрипта в папку `mac_version/`.
- Печать на macOS реализована через генерацию штрихкодов средствами Python (`python-barcode` + `Pillow`) и отправку напрямую в системную очередь печати (`CUPS` / `lpr`). Шаблоны `.lbx` на Mac не используются.

## [1.0.1] - 2026-05-13
### Исправлено / Улучшено
- Удалена жесткая привязка к файлу `Interop.bpac.dll` установленного SDK. Обращение к принтеру теперь идет напрямую через системные COM-объекты.
- Исправлено обращение к файлу шаблона `Label.lbx` (теперь используется динамический путь относительно директории скрипта, что предотвращает ошибки при нестандартном запуске).

## [1.0.0] - Начальная версия
### Добавлено
- Графический интерфейс на `Tkinter` (Python) для ввода инвентарных номеров.
- Поддержка распознавания списка номеров (ограничители: запятая, пробел, новая строка).
- Асинхронная отправка на принтер в отдельном потоке (UI не зависает).
- `PowerShell`-скрипт (`print.ps1`) для интеграции с Brother bPAC3 SDK.
- Пакетная печать (Batch Print) в рамках одной сессии принтера для повышения скорости печати списка этикеток.
- `BAT`-скрипт для быстрого запуска программы без консольного окна.
