# 🖨️ Brother Label Printer

Утилита для быстрой печати наклеек на принтерах Brother (через штрихкод или текстом). Работает на Windows и macOS.

---

## 🚀 БЫСТРЫЙ СТАРТ (Windows)

Самый простой способ — скачать готовый файл, который не требует установки Python:

👉 **[СКАЧАТЬ Label_Printer.exe](https://github.com/schatten08/label-printer/raw/main/src/windows_version/dist/Label_Printer.exe)**

*После нажатия на ссылку файл должен скачаться автоматически. Если открылся сайт GitHub с надписью "file too big", нажмите кнопку **Download** или **View raw**.*

---

## 📦 УСТАНОВКА (macOS)

Чтобы запустить программу на Mac:

1.  Скачайте архив проекта (Зеленая кнопка **<> Code** -> **Download ZIP**) или склонируйте репозиторий.
2.  Зайдите в папку [setup/](setup/)
3.  Запустите файл [Install_Mac.command](setup/Install_Mac.command) (двойным кликом).

**Что сделает установщик:**
- Проверит наличие Python (и предложит установить, если его нет).
- Автоматически установит все необходимые библиотеки.
- Создаст удобный ярлык на вашем Рабочем столе.

## 🛠️ Основные функции

### 1. 📝 Печать списка (List)
Вставьте список серийных номеров или инвентарников (по одному в строке) и нажмите **Print**. Каждая строка превратится в отдельную наклейку со штрихкодом.

### 2. 🔍 Сканер коробок (Box Scanner)
Свяжите SN и ярлык (Asset Tag):
1. Вставьте список пар "SN -> Label" (например, из Excel).
2. Сканируйте заводской номер на коробке.
3. Принтер моментально напечатает соответствующую EPAM-наклейку.

### 3. 📋 Инвентаризация (Inventory Audit)
1. Загрузите базу данных (SN, Модель, Владелец).
2. Сканируйте всё подряд.
3. Программа визуально отметит найденное, покажет прогресс (Found: X / Y) и позволит выгрузить отчет в CSV.

### 4. ✍️ Произвольная печать (Direct Print)
Напишите любой текст (например, имя или "НЕ ВКЛЮЧАТЬ"). Каждая строка будет напечатана крупно, по центру, без штрихкодов.

## 🔄 Обновления
Программа умеет обновляться сама:
- Нажмите кнопку **"🔄 Check for Updates"** в интерфейсе.
- Если у вас установлен Git, программа скачает новую версию и перезапустится.
- Если Git нет, она предложит скачать актуальную версию вручную.

## 📋 Технические подробности

### Требования
- **Принтер**: Серия Brother QL (тестировалось на QL-810W).
- **Windows**: Требуется установленный [Brother bPAC SDK](https://support.brother.com/g/s/es/dev/en/bpac/index.html).
- **macOS**: Используется библиотека `brother_ql` для прямой печати через USB/Wi-Fi.
