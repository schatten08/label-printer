# 🖨️ Brother Label Printer

Утилита для быстрой печати наклеек на принтерах Brother (через штрихкод или текстом). Работает на Windows и macOS.

---

## 🚀 БЫСТРЫЙ СТАРТ (Windows)

Для работы программы на Windows **обязательно** должен быть установлен системный компонент от Brother (один раз):

1.  **⚠️ ШАГ 1 (ОБЯЗАТЕЛЬНО)**: Скачайте и установите **[bPAC Client Component](https://github.com/schatten08/label-printer/raw/main/setup/bPACClientComponent_x64.msi)** (или с [сайта Brother](https://support.brother.com/g/s/es/dev/en/bpac/index.html)). Без этого программа выдаст ошибку "COM-объект".
2.  **Шаг 2**: Скачайте и запустите саму программу:
    👉 **[СКАЧАТЬ Label_Printer.exe](https://github.com/schatten08/label-printer/raw/main/src/windows_version/dist/Label_Printer.exe)**

---

## 📦 УСТАНОВКА (macOS)

1.  Скачайте архив проекта (Кнопка **<> Code** -> **Download ZIP**).
2.  Зайдите в папку [setup/](setup/) и запустите [Install_Mac.command](setup/Install_Mac.command).

---

## 🛠️ Основные функции
- **📝 Список**: Печать пачки номеров из буфера обмена.
- **🔍 Сканер**: Печать наклейки EPAM по заводскому серийнику.
- **📋 Инвентарка**: Визуальный чек-лист и отчет в CSV.
- **✍️ Текст**: Печать произвольного текста без штрихкодов.

---

## ⚠️ Вниманию пользователей (Антивирусы)
Так как программа самописная и не имеет платной цифровой подписи, **Microsoft Defender или Google Chrome** могут посчитать её подозрительной при скачивании или запуске.
- Если Chrome блокирует скачивание: нажмите `Ctrl+J` -> `Keep dangerous file`.
- Если Windows блокирует запуск: нажмите `Подробнее` -> `Выполнить в любом случае`.
